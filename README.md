# Rehearsal Room

A pre-meeting rehearsal tool for a Business Analyst. Before a deck, memo or
recommendation goes to leadership, a panel of simulated stakeholders reads it
independently, an Advocate and a Challenger argue over it, a Coach restructures
it, and a Judge turns everything into a pre-meeting brief: what to fix, what
you will be asked, and how to answer.

Why it is built this way: [docs/DESIGN.md](docs/DESIGN.md).

Nothing lives in a Downloads folder or on a single machine. The repo is the
source of truth for code and personas; the claude.ai artifact holds your data.

## Three ways to run it, same pipeline

### 1. The web app (use this)

Open the artifact link above. Pick a mode, paste a deck outline or memo, add
what you are worried about, press Rehearse. Each role appears as its own
message with an avatar and a stance; the Judge's brief is highlighted. Ask any
role a follow-up afterwards. After the real meeting, press "Record what was
actually asked" on the Judge's message so the panel learns.

Runs on your own Claude account through the artifact runtime. No API key,
nothing to install.

### 2. Inside Claude Code

Open a Claude Code session on this repository and type `/rehearse preread`
(or `framing`, `method`, `stakeholder`, `decide`). Claude orchestrates the run
with one subagent per role and sends you the HTML report.

### 3. Python CLI with your own API key

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
export ANTHROPIC_API_KEY=...        # or `ant auth login`

rehearse run -m preread -i examples/inputs/sample_preread.md --mock   # pipeline check, no model calls
rehearse run -m preread -i examples/inputs/sample_preread.md -w "Finance will question the sizing baseline"
rehearse modes | rehearse roles | rehearse sessions
rehearse debrief <session id>
```

`-p/--panel` replaces the mode's default panel, `-a/--add` adds to it,
`--language zh-TW` switches output language. `rehearse stage init|next` is the
staged form the Claude Code skill drives.

## Changing things

- **A role sounds wrong.** Edit its file in `roles/`. No code changes.
- **Different default panel for a mode.** Edit `config/modes.yaml`.
- **Updated profile defaults.** Edit `profile/workplace.md`.
- **Then rebuild and republish the app:**

```bash
python scripts/build_app.py          # writes app/dist/index.html
# publish app/dist/index.html to the artifact URL above (Claude Code does this on request)
```

## Input rules

Plain Markdown or text. For a deck, paste slide titles and key messages. Use
placeholders such as `[X]`, `[N]`, `[$M]` for real figures; roles are told to
treat them as present and to ask about provenance, not about the blank.

**Keep it de-identified.** No customer data, no actual figures, no verbatim
internal documents. Check your employer's policy on external AI tools before
using work material.
